# Hello World

A minimal example skill. Copy this folder as a starting point for new skills.

## Instructions

When this skill is invoked, greet the user warmly and let them know they are
using the `hello-world` example skill from the autilOS skills collection.

## Authoring notes

- The folder name **must** match the `name` field in the frontmatter above.
- `description` should clearly state *what the skill does* and *when to use it*.
- Everything below the frontmatter is the instruction body the agent reads.
